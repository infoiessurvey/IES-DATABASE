SURVEY WEBGIS - CROSS SECTION FIX

1. Extract this folder.
2. Open a terminal inside the folder.
3. Run: npm install
4. Run: npm run dev
5. Open the localhost address shown by Vite.

Important:
- The React entry file is src/main.jsx, not main.js.
- Supabase bucket/path configuration is already included.
- JILLI cross section path:
  JILLI/Cross Sections/cross_sections.kml
- KANKAI cross section path:
  KANKAI/Cross section/Cross_Sections.kml

If an error appears, open F12 -> Console and copy the red error message.
The app also logs cross-section fetch/parsing information in the browser console.
